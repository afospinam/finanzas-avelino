# Finanzas para la vida — Versión 2

Sitio web educativo interactivo para estudiantes de 9.º a 11.º de la Institución Educativa Avelino Saldarriaga.

## Propósito

Fortalecer conocimientos y habilidades para comprender el dinero, elaborar presupuestos, planear metas de ahorro, analizar créditos, introducir conceptos de inversión y prevenir fraudes.

## Novedades de la versión 2

- Diseño tipo aplicación y laboratorio financiero.
- Seis módulos navegables sin recargar la página.
- Aula interactiva con cuatro modos: comprender, explorar, practicar y comprobar.
- Cinco simuladores con gráficas SVG generadas localmente:
  - presupuesto;
  - ahorro;
  - crédito;
  - inversión;
  - inflación y poder adquisitivo.
- Misión antifraude con puntaje visual.
- Biblioteca de recursos oficiales con filtros y búsqueda.
- Integración del tablero **Tasas y desembolsos por modalidad de crédito** de la Superintendencia Financiera.
- Recurso para planear una visita a la Exhibición Monetaria Interactiva de Medellín.
- Videos cargados bajo demanda mediante `youtube-nocookie.com`.
- Sin registro, bases de datos ni envío de información personal.

## Tecnologías

- HTML5
- CSS3
- JavaScript puro
- SVG para las gráficas
- GitHub Pages

No requiere instalación, compilación, dependencias ni servidor backend.

```text

```

## Publicación en GitHub Pages

1. Crear o utilizar el repositorio público `finanzas-para-la-vida`.
2. Subir `index.html`, `README.md` y `.nojekyll` a la raíz.
3. Realizar el commit.
4. Entrar en **Settings → Pages**.
5. Seleccionar **Deploy from a branch**.
6. Elegir la rama `main` y la carpeta `/ (root)`.
7. Guardar.

URL esperada:

```text
https://afospinam.github.io/finanzas-para-la-vida/
```

## Actualización

Para reemplazar la versión anterior, se debe sustituir el archivo `index.html` del repositorio por el de esta versión. El nombre del repositorio y la configuración de GitHub Pages pueden conservarse.

## Privacidad

Los datos ingresados en simuladores, cuestionarios y retos se procesan únicamente en el navegador. No se almacenan ni se envían a servidores.

## Advertencia educativa

Las calculadoras son aproximaciones pedagógicas. No constituyen asesoría financiera ni recomendaciones para adquirir productos, solicitar créditos o realizar inversiones.
